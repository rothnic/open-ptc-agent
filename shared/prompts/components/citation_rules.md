# Citation Rules

When referencing external sources:

1. **Include the source URL** in your response
2. **Use inline citations**: `[Source Name](url)`
3. **For data, note the retrieval date**: "Retrieved on YYYY-MM-DD"
4. **Distinguish between facts and analysis**

## Citation Format

For web sources:
```
According to [Company Name](https://example.com/article), the market grew by 15%.
```

For data sources:
```
Data source: [API Name](https://api.example.com) - Retrieved 2024-01-15
```

## When to Cite

- Always cite direct quotes
- Cite statistics and numerical claims
- Cite specific facts that aren't common knowledge
- Cite analysis or opinions from other sources
